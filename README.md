# 8-bit OLED Thing

A versatile "No Load" 8 input Digital Signal status monitor / Hex Display / a STM8S Microcontroller dev board / a Dice etc.

Homepage: https://digicoolthings.com/8-bit-oled-thing-this-is-pretty-awesome/

Firmware is programmed via the SWIM interface, using a ST-LINK V2 USB Programmer (or alternative), via ST Visual Programmer.

Handout provides board connections and operating modes.
